# Privacy Policy · 隐私政策

**Last updated / 最后更新：2026-11-12**

4Link（四连引力）是一款离线优先的棋类游戏。项目不设账号系统，不采集个人身份信息，也不含广告或第三方统计 SDK。

4Link is an offline-first board game. It has no user accounts, collects no personally identifying information, and ships no advertising or third-party analytics SDKs.

---

## English

### What we do not collect

- No accounts, sign-up, e-mail addresses or phone numbers.
- No telemetry, crash reporting, device identifiers or advertising IDs.
- No cookies used for tracking or profiling.

### Data stored on your device

Game progress, statistics, language and appearance settings, and any custom board or piece images you import are stored locally in your browser's `localStorage` (or the app's local storage on Android/Windows). This data never leaves your device and is removed when you clear the app's site data or uninstall the app.

### Online play

The online mode uses WebRTC peer-to-peer connections, optionally through a WebSocket relay server. Only the data required to run a match is transmitted: room codes, board state and move messages, plus the connection metadata needed to establish the session (IP addresses, as with any network connection). Messages are relayed in transit and are not stored by the project.

The static site is hosted on GitHub Pages, which receives standard HTTP request logs under [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement). If you use a self-hosted relay, that server's operator is responsible for its logs.

### Custom images

Images you import are read locally in the browser and stored on your device only. They are never uploaded.

### Changes and contact

Material changes to this policy will be published in this file. Questions can be raised via [GitHub Issues](https://github.com/AdLambXD/4link/issues).

## 中文

### 不采集的内容

- 没有账号、注册、邮箱或手机号。
- 没有埋点、崩溃上报、设备标识或广告标识。
- 没有用于追踪或画像的 Cookie。

### 保存在你设备上的数据

游戏进度、统计数据、语言与外观设置，以及你导入的棋盘或棋子图片，全部保存在浏览器的 `localStorage`（Android / Windows 版本为应用本地存储）中。这些数据不会离开你的设备，清除站点数据或卸载应用即被删除。

### 联机对战

联机使用 WebRTC 点对点连接，可选择经过 WebSocket 中继服务器。传输的只有对局必需的数据：房间码、棋盘状态与落子消息，以及建立连接所需的网络信息（与任何网络连接一样包含 IP 地址）。消息仅做转发，项目不存储这些内容。

静态站点托管在 GitHub Pages，其访问日志适用 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement)。若使用自建中继，日志由该服务器的运营者负责。

### 自定义图片

导入的图片仅在浏览器本地读取并保存，不会上传。

### 变更与联系方式

政策如有实质变更会更新本文件。问题可通过 [GitHub Issues](https://github.com/AdLambXD/4link/issues) 反馈。
